# cobaIonicDua — Chemistry

Hasil build produksi (Ionic + Angular + Cordova) dari aplikasi media pembelajaran kimia **titrasi asam basa**. Repo ini hanya berisi file hasil kompilasi (JS ber-hash, CSS, aset), bukan kode sumber.

Halaman yang tersedia antara lain: KD, IPK, materi (pengenalan, titrasi, indikator, titik ekuivalen, praktikum, video), uji/latihan soal, kalkulator, dan profil pengembang. Aset gambar dan video ada di `assets/`. Kode sumber versi serupa ada di repo `IonicTitrasi`.

## Menjalankan
Sajikan folder ini dengan server statis, misalnya:
```bash
npx serve .
```
(`index.html` memakai `<base href="/">`, jadi harus disajikan dari root server.)
